\# Проект: Комплексный текстовый анализатор на Python



Данный проект представляет собой набор консольных скриптов для базовой очистки, нормализации, модификации и глубокого лингвистического анализа текстовых данных на языке Python. Проект разбит на 4 независимых модуля, каждый из которых решает конкретную задачу обработки строк.



\---



\## 📂 Структура проекта и описание модулей



\### 1. `normalize.py` — Нормализация текста

Скрипт удаляет избыточные пробелы и выравнивает структуру текста, сохраняя исходный регистр букв.

\* \*\*Алгоритм работы:\*\*

&#x20; 1. Удаляет все начальные и конечные пробельные символы (пробелы, табуляцию `\\t`, переносы строк `\\n`) с помощью `.strip()`.

&#x20; 2. Разбивает строку по любым группам пробелов с помощью `.split()`, изолируя слова.

&#x20; 3. Собирает строку обратно через `' '.join()`, гарантируя строго \*\*один пробел\*\* между словами.

&#x20; 4. Подсчитывает общее количество слов (длина списка после `.split()`). Знаки препинания, прикрепленные к буквам, остаются частью слова.

\* \*\*Пример работы:\*\*

&#x20; \* \*Вход:\* `  Быстрый   коричневый   лис...  `

&#x20; \* \*Выход:\* `Быстрый лис...` | \*Слов:\* `2`



\### 2. `palindrome.py` — Проверка на палиндром

Скрипт проверяет, является ли введенная строка палиндромом (читается ли она одинаково слева направо и справа налево).

\* \*\*Правила валидации:\*\*

&#x20; \* Игнорируется регистр символов (все приводится к нижнему регистру через `.lower()`).

&#x20; \* Удаляются только обычные пробелы `" "`.

&#x20; \* \*\*Важно:\*\* Все остальные знаки (запятые, точки, дефисы, восклицательные знаки) \*\*сохраняются\*\* и участвуют в сравнении «как есть».

\* \*\*Режимы проверки:\*\*

&#x20; 1. \*\*Быстрый (Срез):\*\* Сравнение очищенной строки с её перевернутой копией `строка\[::-1]`.

&#x20; 2. \*\*Оптимальный (Цикл):\*\* Попарное сравнение символов с краев к центру. Цикл завершается на середине строки (`длина // 2`), что экономит память.

\* \*\*Выходные сообщения:\*\*

&#x20; \* `Нет текста` — если после удаления пробелов строка пуста.

&#x20; \* `Палиндром` — если текст симметричен.

&#x20; \* `Не палиндром` — если симметрия нарушена.



\### 3. `replace.py` — Замена с подсчетом

Скрипт автоматизирует замену определенных разделителей в тексте и предоставляет статистику изменений.

\* \*\*Алгоритм работы:\*\*

&#x20; 1. Находит и подсчитывает точное количество символов двоеточия (`:`) в исходном тексте с помощью метода `.count(':')`.

&#x20; 2. Заменяет все найденные двоеточия на дефисы (`-`) с помощью метода `.replace(':', '-')`.

&#x20; 3. Выводит на экран количество выполненных замен и финальный измененный текст.



\### 4. `variant.py` — Фильтрация, очистка и поиск подстрок

Мощный инструмент для пословного анализа текста, который удаляет «мусорные» знаки препинания с краев слов и осуществляет гибкую проверку содержимого.

\* \*\*Алгоритм работы:\*\*

&#x20; 1. Исходная строка разбивается на слова по пробелам.

&#x20; 2. Для каждого слова удаляются краевые символы `.,!?;:` с помощью метода `word.strip(".,!?;:")`.

&#x20; 3. Очищенное слово переводится в нижний регистр (`.lower()`).

&#x20; 4. Если слово состояло только из знаков препинания (например, `...`), после очистки оно становится пустым и полностью пропускается.

&#x20; 5. Скрипт выводит каждое валидное слово в новую строку, сохраняя дубликаты, и в конце выводит общее число совпадений. Если слов нет, выводит `Нет совпадений` и количество `0`.

\* \*\*Внутренние проверки безопасности и поиска:\*\*

&#x20; \* Обращение к первому символу `word\[0]` и последнему `word\[-1]` происходит строго \*\*после\*\* проверки на пустоту, чтобы не вызвать ошибку `IndexError`.

&#x20; \* Проверка начала и конца слова выполняется методами `.startswith()` и `.endswith()`.

&#x20; \* Поиск цифр внутри слова производится методом `.count()`, а проверка вхождения подстрок (например, `"край"`, `"рама"`) — с помощью оператора `in`.

\## 📊 Таблица проверочных значений (Контрольный пример)



Для верификации корректности работы скрипта `variant.py` используется тестовый текст:  

> \*\*`Анна, армия! Я читаю. Книга, край, рама..`\*\*



Ниже приведена аналитическая таблица обработки слов:



| Очищенное слово | Начало (`startswith`) | Конец (`endswith`) | Проверка вхождения (`in` / `count`) |

| :--- | :--- | :--- | :--- |

| \*\*анна\*\* | `startswith("а")` -> \*\*True\*\* | `endswith("а")` -> \*\*True\*\* | Символ `"н"` встречается `2` раза |

| \*\*армия\*\* | `startswith("а")` -> \*\*True\*\* | `endswith("я")` -> \*\*True\*\* | Содержит подстроку `"мия"` -> \*\*True\*\* |

| \*\*я\*\* | `startswith("я")` -> \*\*True\*\* | `endswith("я")` -> \*\*True\*\* | Длина слова = 1 символ |

| \*\*читаю\*\* | `startswith("ч")` -> \*\*True\*\* | `endswith("ю")` -> \*\*True\*\* | Цифры отсутствуют (`count` цифр = 0) |

| \*\*книга\*\* | `startswith("к")` -> \*\*True\*\* | `endswith("а")` -> \*\*True\*\* | Содержит подстроку `"ниг"` -> \*\*True\*\* |

| \*\*край\*\* | `startswith("к")` -> \*\*True\*\* | `endswith("й")` -> \*\*True\*\* | Содержит подстроку \*\*`"край"`\*\* / \*\*`"рай"`\*\* -> \*\*True\*\* |

| \*\*рама\*\* | `startswith("р")` -> \*\*True\*\* | `endswith("а")` -> \*\*True\*\* | Содержит подстроку \*\*`"рама"`\*\* / \*\*`"рама"`\*\* -> \*\*True\*\* |



\* \*\*Итоговое количество совпадений (всего валидных слов):\*\* `7`

\## 🚀 Инструкция по запуску



\### Требования

\* Установленный интерпретатор \*\*Python версии 3.6\*\* или выше.



\### Порядок запуска

1\. Склонируйте репозиторий или скачайте файлы скриптов в одну папку.

2\. Откройте терминал (командную строку) и перейдите в директорию с проектом:

&#x20;  ```bash

&#x20;  cd путь/к/вашей/папке/проекта

&#x20;  ```

3\. Запустите необходимый вам скрипт с помощью команды `python`:

&#x20;  ```bash

&#x20;  python normalize.py

&#x20;  python palindrome.py

&#x20;  python replace.py

&#x20;  python variant.py

&#x20;  ```

4\. Введите текст по запросу программы в консоли и нажмите `Enter` для получения результата.
